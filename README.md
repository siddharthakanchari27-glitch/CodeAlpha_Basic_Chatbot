# CodeAlpha_Basic_Chatbot
Basic chatbot using simple python program
CodeAlpha Task 4 – Basic Chatbot

Project Description

The Basic Chatbot is a simple Python program that interacts with users through predefined messages. It accepts user input and responds according to specific rules.

Features

- Responds to greetings such as hello.
- Answers the question "How are you?"
- Ends the conversation when the user types bye.
- Handles unknown messages with a default response.
- Uses a loop to continue the conversation.

Technologies Used

- Python
- Functions
- While loop
- If-elif-else statements
- String handling
- Input and output

How to Run

1. Install Python.
2. Download or clone the repository.
3. Open the project in VS Code.
4. Run "python basic_chatbot.py".

Learning Outcome

This project demonstrates the basics of rule-based chatbot development and Python programming logic.
